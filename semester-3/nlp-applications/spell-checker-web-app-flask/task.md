PART-A
Spell Checker Application

**Task A — Problem statement**
Develop a spell-checker application that allows users to input text. The application should be a web service with a user-friendly interface. The spell checker must identify misspelled words and suggest corrections.

**Requirements**

* **Web interface 

  * Build a front end using HTML and JavaScript.
  * Use Flask (Python) for the back end to handle requests and responses.
  * Provide a text area for user input.
  * Display both the original and corrected text on the web page and print them to the terminal.

* **Spell-checking functionality 

  * Implement spell checking using a library of your choice.
  * Detect misspelled words in the input text.
  * Provide suggested corrections for each misspelling.

* **Integration

  * Seamlessly integrate front end and back end.
  * Handle user input, perform spell checking, and display corrected text on the page.

---

**Deliverables

* Well-documented code (Python back end and front end).
* Instructions for running the application locally.
* A brief report explaining design choices and challenges faced.
